# Quiz Culture IA - INSERSITE

Bienvenue dans le Quiz Culture IA INSERSITE! Ce quiz teste vos connaissances sur l'Intelligence Artificielle, de manière progressive (du plus simple au plus avancé).

## Comment jouer
1. Ouvrez `index.html` dans votre navigateur web.
2. Entrez votre nom et prénom.
3. Répondez aux 10 questions numérotées en **15 secondes maximum** par question (le timer compte à rebours et devient rouge à 7 secondes restantes).
4. Validez chaque réponse pour voir l'explication et les points gagnés.
5. À la fin, consultez votre score total et le classement.
6. **Scoring** : Questions faciles = 1 point, intermédiaires = 2 points, avancées = 3 points (score max : 18/18).
7. **Récompenses** :
   - Applaudissements à chaque bonne réponse (ajoutez un fichier `applause.mp3` pour le son).
   - Confettis si votre score est ≥ 12/18 (plus que la moyenne).

## Les questions et réponses

### Question 1 : L’IA est principalement utilisée pour :
- **Options** : Remplacer totalement l’humain, Assister et améliorer le travail humain, Fonctionner sans données
- **Bonne réponse** : Assister et améliorer le travail humain
- **Explication** : L’IA est un outil d’assistance, pas un remplaçant total.

### Question 2 : Quels usages sont adaptés à l’IA en entreprise ?
- **Options** : Automatiser des tâches répétitives, Prendre des décisions juridiques seules, Aider à l’analyse de données
- **Bonnes réponses** : Automatiser des tâches répétitives, Aider à l’analyse de données
- **Explication** : L’IA aide, mais la décision finale reste humaine.

### Question 3 : Quelle est une limite importante de l’IA actuelle ?
- **Options** : Elle peut penser comme un humain, Elle nécessite des données de qualité, Elle fonctionne sans électricité
- **Bonne réponse** : Elle nécessite des données de qualité
- **Explication** : L’IA dépend de la qualité des données pour fonctionner correctement.

### Question 4 : Qu'est-ce que le Machine Learning ?
- **Options** : Un type d'ordinateur, Une méthode où les machines apprennent des données, Un langage de programmation
- **Bonne réponse** : Une méthode où les machines apprennent des données
- **Explication** : Le Machine Learning permet aux algorithmes d'apprendre et de s'améliorer à partir de données.

### Question 5 : Quelle est la différence entre IA faible et IA forte ?
- **Options** : L'IA faible est plus intelligente, L'IA faible est spécialisée, l'IA forte est générale, L'IA forte est plus lente
- **Bonne réponse** : L'IA faible est spécialisée, l'IA forte est générale
- **Explication** : L'IA faible (comme Siri) est bonne dans un domaine, l'IA forte pourrait penser comme un humain.

### Question 6 : Quels sont des exemples d'IA en entreprise ?
- **Options** : Chatbots pour le service client, Jeux vidéo, Analyse prédictive des ventes
- **Bonnes réponses** : Chatbots pour le service client, Analyse prédictive des ventes
- **Explication** : L'IA aide à automatiser et analyser dans un contexte professionnel.

### Question 7 : Qu'est-ce que le Deep Learning ?
- **Options** : Un réseau neuronal profond, Un type de base de données, Un logiciel de bureautique
- **Bonne réponse** : Un réseau neuronal profond
- **Explication** : Le Deep Learning utilise des réseaux de neurones pour traiter des données complexes.

### Question 8 : Quels sont des risques éthiques de l'IA ?
- **Options** : Perte d'emplois, Biais dans les décisions, Amélioration de la productivité
- **Bonnes réponses** : Perte d'emplois, Biais dans les décisions
- **Explication** : L'IA peut amplifier les biais existants et changer le marché du travail.

### Question 9 : Qu'est-ce que GPT ?
- **Options** : Un modèle de langage génératif, Un type de processeur, Un protocole internet
- **Bonne réponse** : Un modèle de langage génératif
- **Explication** : GPT est une IA capable de générer du texte, comme ChatGPT.

### Question 10 : Quel est l'avenir probable de l'IA selon les experts ?
- **Options** : L'IA remplacera tous les emplois, L'IA assistera les humains dans de nombreux domaines, L'IA disparaîtra
- **Bonne réponse** : L'IA assistera les humains dans de nombreux domaines
- **Explication** : L'IA est vue comme un outil complémentaire, pas un remplaçant total.
